## ۲) انتخاب نهایی: **یادچه / Yadche**

**دلایل:**

1. **ریشه‌ی معنایی دقیق:** از «یاد» (memory) ساخته شده — مستقیماً به هدف محصول
   (یادداشت، یادآوری، نگه‌داشتن خاطرات) می‌خورد.
2. **تمایز از واژه‌ی عمومی:** «یادداشت» یک کلمه‌ی عام است؛ «یادچه» برندپذیر است و
   در جستجوها با هیچ اپ مشهوری اشتباه گرفته نمی‌شود.
3. **پسوند «‌چه»:** پسوند مصغر فارسی حس صمیمیت، کوچکی و دوست‌داشتنی بودن می‌دهد
   (مثل: قهوه‌چه، دفترچه) و هویت ایرانیِ مدرن می‌سازد.
4. **تلفظ بین‌المللی:** «Yadche» در انگلیسی هم راحت تلفظ می‌شود.
5. **کوتاهی:** دو هجایی؛ برای آیکون، splash و نام فایل APK عالی است.
6. **دسترسی:** `com.yadche.notes` تمیز و خالی است.

## ۵) تایپوگرافی

- فونت اصلی: **Vazirmatn** (متن‌باز، بسته‌شده در پکیج — آفلاین کار می‌کند)

## ۶) آیکون

**ایده:** صفحه‌ی یادداشت با تای‌ویداشت از سمت راست (RTL) + نشانک رنگی گرادیانی
(Bookmark) + درخشش (Spark) — روی بلوک گرادیانی بنفش→صورتی→کهربا با نور و عمق.

**لایه‌ها (assets/):**

| فایل                      | نقش                                               |
| ------------------------- | ------------------------------------------------- |
| `logo.svg` / `icon.png`   | مستر ۱۰۲۴×۱۰۲۴ (PWA، favicon، OG)                 |
| `icon-background.svg/png` | لایه‌ی Background آیکون تطبیقی اندروید            |
| `icon-foreground.svg/png` | لایه‌ی Foreground (محتوا داخل Safe Zone 66/108)   |
| `icon-monochrome.svg/png` | نسخه‌ی Monochrome برای Themed Icons (اندروید ۱۳+) |
| `splash.svg/png`          | Splash Screen ثابت اندروید (۲۷۳۲×۲۷۳۲)            |

**خروجی‌ها:**

- اندروید: همه‌ی سایزهای mipmap + adaptive + monochrome با `@capacitor/assets`
- PWA: `icon-192`، `icon-512`، `maskable-512`
- `favicon.svg`، `favicon-32.png`، `apple-touch-icon.png`
- `og.png` (۱۲۰۰×۶۳۰) برای README و شبکه‌های اجتماعی

**بازتولید:** `npm run android:assets`

## ۷) Splash انیمیت‌شده

1. ظاهر شدن نرم لوگو (spring + blur)
2. درخشش نور روی لوگو (shine sweep)
3. ظاهر شدن نام و شعار
4. محو شدن روان به سمت اپ
   — با احترام به `prefers-reduced-motion`
